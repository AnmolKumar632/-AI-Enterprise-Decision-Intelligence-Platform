⚡ Platform Engine Core Capabilities

AEDIP coordinates state-of-the-art analytical components for commercial scale deployment.

AI Data Preprocessing

Automatically discovers schema models. Imputes missing fields via median/mode metrics and filters skewness or outliers via Isolation Forest percentiles.

AutoML Model Fits

Fits regression and classification targets using Random Forests, Extra Trees, Gradient Boosting, and XGBoost, ranking parameter fits on a metric leaderboard.

Explainable AI (XAI)

Maps localized pertubations onto model coefficients, calculating feature weights so analysts understand black-box modeling choices.

Enterprise Security

Secures relational sessions via stateless Bearer JSON Web Tokens (JWT), filters NoSQL injections, and implements strict Role-Based Access Controls (RBAC).

⚙️ Local Installation Guide

Deploy the complete Python backend, MongoDB document storage, and Django endpoints on your local system.

1. Prepare Environment & Workspace

Open a terminal, navigate to your workspace directory, and initialize a local Python virtual environment to prevent dependency conflicts:

# Navigate to workspace
cd "c:\Users\csp\OneDrive\Documents\AI Enterprise Decision Intelligence"

# Initialize virtual environment
python -m venv .venv

# Activate environment (Windows)
.venv\Scripts\activate

# Activate environment (macOS/Linux)
source .venv/bin/activate

2. Install System Dependencies

Install all backend Django controllers, scikit-learn AutoML pipelines, reporting libraries, and database connectors:

pip install -r requirements.txt

3. Ensure MongoDB & Services are Active

AEDIP stores unstructured projects and datasets in MongoDB. Ensure your local server is active on standard port `27017`:

# Method A: Check native Windows MongoDB service
Get-Service -Name MongoDB

# Method B: Start via Docker Compose (includes Redis for Celery)
docker-compose up -d

4. Run Relational Database Migrations

Initialize relational tables for administrative users, login security parameters, and audit logging on SQLite:

python manage.py migrate

5. Startup Development Server

Fire up the web engine locally and visit the platform dashboard:

# Start server
python manage.py runserver 127.0.0.1:8000

Open http://127.0.0.1:8000/ in your browser. Register an account, log in, create a workspace project, and start modeling!
